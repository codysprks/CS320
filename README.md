
# CS-320 Software Test, Automation, and Quality Assurance

This repository contains work completed during CS-320 Software Test, Automation, and Quality Assurance. The projects demonstrate my experience with creating software requirements, developing unit tests, and using testing techniques to make sure software functions correctly.

## How can I ensure that my code, program, or software is functional and secure?

I can ensure that my software is functional and secure by testing the code throughout the development process. In this course, I created unit tests to check both valid and invalid inputs and made sure the program followed the required constraints. Testing different situations helped me find errors and confirm that the software behaved as expected.

## How do I interpret user needs and incorporate them into a program?

I interpret user needs by reviewing the requirements and determining what the program must do. I then use those requirements when designing the code and creating test cases. For example, the contact service had specific requirements for contact IDs, names, phone numbers, and addresses. I used those requirements to determine how the program should validate information and how it should be tested.

## How do I approach designing software?

I approach software design by first understanding the requirements and then breaking the program into smaller parts. I try to keep each class and method focused on a specific responsibility, so the code is easier to understand, test, and maintain. I also use testing throughout development instead of waiting until the program is finished. This helps me identify problems earlier and make improvements as I continue developing the software.
